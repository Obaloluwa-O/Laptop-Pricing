Exploratory Data Analysis Project with Python – Laptop Pricing Dataset

I recently completed an Exploratory Data Analysis (EDA) project using Python in Jupyter Notebook to uncover key drivers of laptop pricing. Leveraging libraries such as pandas, numpy, scipy, seaborn and matplotlib, I analyzed the dataset through descriptive statistics, visualizations, correlations, and pivot tables.

Key findings included:
CPU frequency, CPU cores, RAM, and GPU showed the strongest positive correlations with price, while features like screen size and weight had weak or negative correlations.
Boxplots revealed distinct price ranges across categories, with Category 5 showing the highest spread and median values.
Regression plots highlighted that higher CPU frequency consistently drive price increases, whereas screen size did not strongly influence price.
A heatmap of GPU vs CPU cores vs Price showed that higher core counts paired with stronger GPUs significantly increased pricing.

This project not only sharpened my skills in data wrangling, visualization, and statistical analysis, but also demonstrated how data-driven insights can explain market pricing dynamics and support smarter decision-making.
